# Echo Architect piano motifs

The six `.m4a` motifs in this directory are derived from the **Upright Piano
KW** collection by FreePats. The collection is dedicated to the public domain
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Source repository: <https://github.com/freepats/upright-piano-KW>, commit
`570f6c60ed2eff67accad3b85d5b452e57a3ad28`.

Source recordings used, all low-velocity FLAC at 44.1 kHz stereo:

| Note | SHA-256 |
| --- | --- |
| C4 | `4382a54ffbb731cc8c7d8d88e322b1d669d6d44ccdca71eb17860d3c81967b4f` |
| D♯4 | `105074540a60b82228cc6d9defb84b37aaab2a18d7526ccbf197500529040ff7` |
| F♯4 | `157fa02c06d4cc768f059ae1954c11f8dabf0dae65da1f94f120570d7d6a50e5` |

Each motif uses a 550 ms attack from the first two notes, 120 ms silence
between notes, and a 750 ms final note. It is AAC-LC in an MP4 container at
44.1 kHz stereo, encoded at 96 kb/s. The catalog stores the matching SHA-256
for each immutable output before publication through Mixli's managed-media
pipeline.
