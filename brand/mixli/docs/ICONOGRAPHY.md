# Iconography

All production UI symbols use a 24×24 grid, 1.8 px optical stroke, round caps/joins, and `currentColor` so theme/state coloring stays in application code.

Use familiar symbols for familiar actions. Do not replace Share, Back, More, Replay, Volume, Camera, Microphone, Search, or Info with brand-specific metaphors simply to appear distinctive. Brand differentiation belongs in the Mixli mark, motion, content and composition.

Filled forms are reserved for the four main navigation destinations: Play, Saved, Create and Me. Share and External Link are intentionally different glyphs.

Recommended visible size is 24 px. Give icons a 44×44 pt iOS hit target and approximately 48×48 logical px on Android/web where practical. Every interactive icon requires an accessibility label.
