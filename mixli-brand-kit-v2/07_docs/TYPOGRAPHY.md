# Typography

## Production choice
- Official wordmark: custom outlined vector, no font dependency.
- Product/UI: Inter Variable 400/500/600.
- Large editorial/marketing: Inter Display 550–650, generally ≥32 px.

## Why
Inter is designed for computer screens, uses a tall x-height for mixed/lowercase readability, and its variable family supports weight and optical-size variation. Using Inter across UI while reserving the Display optical design for large brand moments avoids another runtime font payload and prevents the visual system from becoming more important than Play content.

## Rules
- Never use Thin/Light for functional UI.
- Do not letterspace body copy.
- Tighten display headings modestly (-1% to -2%).
- Uppercase labels should be rare; if used, 4%–8% tracking maximum.
- Preserve Dynamic Type / text scaling; never rasterize functional text.
- The tagline asset is provided as outlined vectors where it is part of the logo lockup.
