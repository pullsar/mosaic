# Iconography

All UI icons are original Mixli production vectors on a 24×24 grid with 1.8px optical strokes and round terminals. They use `currentColor` so theme/state coloring remains in code.

Use familiar symbols for familiar actions. Do not replace Share, Back, More, Replay, Volume, Camera, Microphone, Search, or Info with brand-specific metaphors. The only intentionally distinctive action symbol is Remix.

Filled forms exist only for the four main navigation destinations: Play, Saved, Create, Me.
