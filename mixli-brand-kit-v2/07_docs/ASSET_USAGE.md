# Asset usage

- `01_logo/`: brand identity only.
- `02_app_icons/`: platform icon exports; light/dark full-square icons are opaque, adaptive foreground is transparent.
- `03_ui_icons/svg/`: production-first assets; prefer these over PNG.
- `04_empty_states/`: text-free illustrations, light/dark variants.
- `05_marketing/`: editable SVG templates and raster previews.
- `06_tokens/`: CSS, Flutter, and design-token sources.
- `08_qa/`: machine and visual QA evidence.
